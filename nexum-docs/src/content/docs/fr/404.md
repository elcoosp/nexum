Nous n'avons pas trouvé la page demandée. L'URL est peut-être obsolète ou la page a été déplacée. Voici les moyens les plus rapides de reprendre votre parcours :

- Vous découvrez nexum ? Commencez par [le tutoriel](/fr/tutorials/getting-started/) — il vous mène d'un projet Cargo vide à la réception d'un lien profond en une dizaine de minutes.
- Vous résolvez un problème précis ? Parcourez les [guides pratiques](/fr/guides/installation/) pour l'installation, la configuration par plateforme, la transmission à instance unique et plus encore.
- Vous recherchez une API ? La [section référence](/fr/reference/nexum/) documente chaque crate publique avec ses signatures exactes.
- Vous voulez comprendre pourquoi nexum fonctionne ainsi ? La [section explications](/fr/explanation/architecture/) couvre l'architecture, les sources d'événements et les principes de conception.

Si vous avez suivi un lien interne au site qui vous a mené ici, merci d'[ouvrir un ticket sur GitHub](https://github.com) afin que nous puissions le corriger.
