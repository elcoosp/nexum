`nexum` gives Rust applications a single, consistent way to handle custom URL schemes. You declare the schemes your app owns, nexum registers them with the operating system, and your code receives every deep-link event — whether the URL arrives from a browser, a second process, or the command line — through one producer-consumer channel.

The workspace is organized so you depend on exactly what you need: [`nexum-core`](/reference/core/) holds the framework-independent primitives, [`nexum-platform`](/reference/platform/) performs OS-level registration, and thin adapter crates expose everything through the idioms of five UI frameworks.

## The ecosystem at a glance

| Crate                                         | Purpose                                                                                 |
| --------------------------------------------- | --------------------------------------------------------------------------------------- |
| [`nexum`](/reference/nexum/)                  | Facade: core + platform + the `#[deep_link]` bootstrap attribute in one dependency      |
| [`nexum-core`](/reference/core/)              | `DeepLinkHub` producer and `DeepLinkHandle` consumer — blocking, async, stream, bounded |
| [`nexum-platform`](/reference/platform/)      | OS registration, single-instance hand-off, plist validation, mobile intake              |
| [`nexum-macros`](/reference/macros/)          | The `#[deep_link(schemes = ["myapp"])]` attribute                                       |
| [`nexum-floem`](/reference/adapters/floem/)   | Floem adapter returning a reactive `ReadSignal<Option<String>>`                         |
| [`nexum-xilem`](/reference/adapters/xilem/)   | Xilem adapter with the `with_deep_links` view wrapper                                   |
| [`nexum-dioxus`](/reference/adapters/dioxus/) | Dioxus adapter with a one-call `launch_desktop` path                                    |
| [`nexum-leptos`](/reference/adapters/leptos/) | Leptos adapter returning `RwSignal<Option<String>>`, wasm-ready                         |
| [`nexum-gpui`](/reference/adapters/gpui/)     | GPUI adapter for Zed-style applications                                                 |

## Platform support

| Platform          | Registration method                       | Runtime detection                 |
| ----------------- | ----------------------------------------- | --------------------------------- |
| **Windows**       | Registry (per-user)                       | CLI arguments                     |
| **macOS**         | `Info.plist` (validator included)         | Apple Events (`GURL` via `objc2`) |
| **Linux**         | `.desktop` file + `xdg-mime`              | CLI arguments                     |
| **Android / iOS** | Declarative (manifest / plist generators) | Framework glue → `mobile::push_*` |
