Welcome to the official blog for **Nexum**!

## What is Nexum?

Framework-agnostic deep linking for Rust — one unified API for custom URL schemes and deep-link events across Windows, macOS, Linux, Android and iOS.

## What to expect here

This blog is the central hub for everything related to Nexum. We will be publishing:

- **Deep dives** into the architecture, design decisions, and inner workings of the project.
- **Tutorials and how-to guides** to help you get up and running quickly.
- **Release notes** and feature announcements as the project evolves.

Whether you are just discovering Nexum or have been using it for a while, we are glad you are here. Stay tuned for our first official deep dive!
