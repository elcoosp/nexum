# ADR 0006 — Omitted Starlight plugins and ecosystem features

**Status:** accepted (2026-11)

## Context

The "bells and whistles" baseline includes a set of HiDeoo-maintained Starlight plugins. Only plugins that are both compatible (peer ranges covering Astro 7.4 / Starlight 0.42) **and** relevant to this project are installed; every omission is documented here rather than silently dropped.

## Installed

| Plugin | Version | Reason |
| --- | --- | --- |
| `starlight-links-validator` | 0.27.0 | Fails the build on broken internal links — a release blocker for a multi-section docs site |
| `starlight-image-zoom` | 0.16.2 | Click-to-zoom for content images |
| `starlight-heading-badges` | 0.8.0 | Heading badges for reference page annotations |

## Omitted

| Plugin | Reason |
| --- | --- |
| `starlight-typedoc` | Generates API docs from TypeScript sources; nexum is a **Rust** workspace with no TypeScript public API. `cargo doc` (already CI-enforced with `-D warnings`) serves the generated Rust reference upstream. |
| `starlight-openapi` | The project ships no OpenAPI specification. |
| `starlight-blog` | The repository has no committed changelog or release feed to source posts from — `CHANGELOG.md` is generated by git-cliff only at tag time. A blog section with no source content would be an empty shell. Revisit if release notes start landing in-repo. |
| `starlight-versions` | The docs describe a single version line (0.3.x); versioned docs are premature for this project's stage. |
| `@astrojs/starlight-docsearch` | No approved Algolia DocSearch application exists. Pagefind (Starlight's default) is the search solution and stays enabled. |

## Consequences

- Search = Pagefind (default, kept).
- API reference pages are hand-authored from the crate inventories, cross-checked against source doc comments and tests.
- Each omitted plugin above should be reconsidered when its triggering precondition changes (TS API surface appears, OpenAPI spec appears, in-repo changelog appears, second docs version appears, DocSearch application approved).
